# BEYBLADE X 能力驅動對戰模擬 V1 技術規格

版本：2026-11-16。狀態：可操作原型。非實際物理量測、非官方勝率引擎。

## 1. 架構與資料

- data/collection.json：19 顆個人收藏，記錄原廠配置、實體來源及旋向。
- data/part-abilities.json：78 筆發售版本對應能力。data/part-abilities.js 為靜態網站使用版本。
- sim-engine.js：唯一計算來源。接受組裝配置、發射設定、亂數種子；提供固定步長即時模擬與批次模擬。
- sim-view.js：把同一份動力狀態呈現為 Three.js 3D 場景，載入失敗時使用 Canvas 2D。
- sim-ui.js：雙方配件、發射器、計分、回合控制、批次統計與 JSON 匯出。

**動力結果先由 sim-engine.js 計算，畫面只負責顯示。** 大量模擬不依賴 3D 動畫。

## 2. 真實來源與模型假設的界線

| 資料 | 目前狀態 | 正確解讀 |
|---|---|---|
| 發售型號、戰刃、固鎖、軸心、CX 模組 | 已記錄 | 品項與原廠配件 |
| 攻擊、防禦、持久、衝刺、抗爆 | 公開零件資料庫 | **相對性能指標**，不是實測力、角速度或概率 |
| 固鎖高度代碼 | 配件資料 | 參考規格，未實測撞擊位置 |
| 重量、質心、轉動慣量、摩擦係數、恢復係數 | 尚未完整量測 | **不能宣稱為已知物理常數** |
| 外形 | 泛用 3D 模型 | 不代表各款陀螺精準三維幾何 |

### 2.1 能力合成公式（沿用現有分析頁權重）

假設 B＝戰刃、R＝固鎖、T＝軸心：
- 攻擊 A = 0.62 B.attack + 0.12 R.attack + 0.26 T.attack + 0.17 T.dash
- 防禦 D = 0.62 B.defense + 0.15 R.defense + 0.23 T.defense + 0.08 T.burst
- 持久 S = 0.62 B.stamina + 0.13 R.stamina + 0.25 T.stamina
- 衝刺 X = T.dash；抗爆 U = T.burst。合成分數裁切至 0～100。
- 自訂 CX 將紋章、主刃與輔助刃的相對能力合成。它不是完整戰刃的實測值。

上述權重是站內建模假設，非官方物理公式。

### 2.2 未校正的動態參數

- 模型質量代理 = 1 + 0.0024 D + 0.0013 A。
- 轉動慣量參考代理 = 0.8 + 0.004 S + 0.002 D（尚未完成實物校正）。
- 旋轉損耗代理 = 1.15 + 0.023(100 − S)。
- 爆裂閾值代理 = 0.52 + 0.0078 U。
- 導軌加速效率代理 = 0.25 + 0.009 X。
- 發射力道輸入範圍 0～14000 SP（模擬參數，預設 10500）；拉線式相對拉條式的 1.04 初始轉速倍率是**假設**，不代表官方 SP 與 RPM 的校正關係。
- 固定模擬時間步：1/120 秒。單回合最多 33 秒（均為模型計時）。
- 場地半徑、位置、速度、碰撞衝量、角速度等均使用**內部無因次單位**。不得誤當實際公尺、公斤、牛頓或 RPM。

模擬每一步更新平面位置、移動速度、旋轉能量、軌道加速、碰撞反彈、爆裂疲勞、停轉與出界條件。此為受能力驅動的簡化動態模型，不是精準的三維剛體接觸解算。

## 3. 1v1 / 3v3 賽制

- 1v1：雙方各一顆，逐回合計分，先到 4 分。
- 3v3：雙方各 3 顆，依 1、2、3 號順序**逐場 1 對 1**，不是六顆同時進場。平手使用相同位置重賽。
- 迴轉勝利 1 分；爆裂或擊飛勝利 2 分；極限勝利 3 分。
- V1 三個位置循環後保持原先順序，未支援官方賽制後續重新排列出戰順序。
- 三顆隊伍：不可重複占用實體零件；一般零件即使異色，只要型號相同也禁止重複。常見 CX 鎖定紋章依例外處理。完整 CX 戰刃也要拆成紋章、主刃、輔助刃計入占用。
- 此原型尚未完全驗證所有專用零件的機械相容性、殿堂零件及各場賽事限制。可選擇不代表實際賽事合法。

## 4. 互動與再現性

- 選擇模式、雙方配件、發射器（拉條／拉線）、0～14000 SP 模擬力道、角度及場地。
- 即時模式：開始、暫停、下一回合、重設；可選 1×、2×、4×。
- 批次模式：25／100／500／1000 場完整模擬比賽。
- 每一場種子由固定起始值產生；相同設定、種子與程式版本可重現。
- 統計顯示我方／對手／平手的**模型頻率**、碰撞與導軌事件，以及各類結局。可匯出 JSON。
- 尚未在零件能力資料庫建立的本機新收藏，不能取得憑空推測的能力值；須先核對來源。

## 5. V1 限制及後續校正

V1 只顯示通用 3D 陀螺，不是逐顆真實 3D 模型；也還不能匯出實拍等級的 MP4。WebGL 不可用時回退為 2D。3D 套件使用外部 CDN，網路載入失敗不影響統計模擬。

未來須量測重量、重心、轉動慣量、軸心與場地摩擦、發射初始轉速、碰撞恢復係數、各種接觸輪廓及爆裂條件。收集實際對戰影片與實驗結果，再校正模型，才能提升對實戰的預測能力。

**模擬結果是此模型下的預測頻率，並非真實對戰測得的勝率。**


## V1.1 修正（畫面與計分一致性）

- 對戰設定新增重置鈕：還原 1v1、Xtreme 模擬盤、亂數種子 966、1 倍速、兩側拉條式發射器、10500 SP 力道及 0° 角度；**保留自訂零件**。旁邊的「重設」仍只負責清除目前比賽分數。
- 場地切換同時修改 sim-engine 的 rail/arena 參數與 sim-view 的盤面：Xtreme 模擬盤包含橘色導軌和出口區標示；練習圓盤使用不同色系且不顯示 Xtreme Line。切換時會清除進行中的比賽，避免兩套設定不一致。
- 選擇配件後，從現有收藏的透明 PNG 讀取戰刃，並在 3D 表面展示。CX 自訂配置以主刃、輔助刃、鎖定紋章多層貼圖近似呈現。固鎖、軸心會改變底部代理零件的形狀或顏色，並在場地下方列出真實來源 PNG 和型號。
- 這些仍是**近似 3D 組裝示意**：圖片是俯視素材，並不能反推出側面幾何、碰撞接觸面、材質與精確重心。因此 **3D 外觀不直接決定物理碰撞**；碰撞始終按資料庫能力合成後的代理參數計算。
- sim-engine 在每回合勝負決定時輸出 terminal 事件：勝方、敗方、結束方式及時間。迴轉結束時敗方自轉歸零；出界、極限、爆裂時記錄相應終結狀態。
- 即時模式先用同一終結狀態播放約 1.2 秒的停轉、出界或解體近似動畫，**然後**更新比分。勝利方式及得分由引擎產生，而不是由畫面預選。
- 非即時批次模式仍直接使用相同的引擎計算，且不引入 1.2 秒畫面等待。
- PNG 如因網路錯誤無法載入，3D 顯示會退回對應的代理幾何；計分仍依選擇的零件能力。完全無法載入 WebGL 時仍保有 Canvas 2D 備援畫面。

核心測試與 UI 迴歸測試參見 tests/sim-smoke.cjs、tests/sim-ui-smoke.cjs。


## V1.2 戰鬥重播風格與音效（依使用者參考影片）

參考影片約 9 秒。後半段展示白色立體競技盤、鮮綠色導軌、深藍技術網格背景、陀螺高速移動、碰撞火花和光軌。前半段為對戰紀錄介面。V1.2 將後半段的對戰呈現作為**視覺參考**，不複製影片、音樂、原始貼圖或配音。

- 3D 模擬盤：深藍網格地板、白色多層外框、淺色盤底、螢光綠 Xtreme Line、出口區及模擬支架。練習盤會隱藏綠色導軌並改換底色。
- 2D 備援：同步改為藍色背景／白色盤／亮綠線，保留同一戰鬥事件計算。與 3D 同步顯示移動光軌、碰撞及導軌特效。
- 效果來源：sim-engine.js 在 hit／dash／finish 事件附帶碰撞位置、強度、時間。sim-view.js 依事件產生粒子火花、衝刺光效及輕微鏡頭震動。特效**不改變物理運算結果**。
- sim-audio.js：透過 Web Audio API 即時合成原創的發射、旋轉、撞擊、Xtreme Dash、爆裂、擊飛／極限、停轉、平手及勝利提示聲。沒有拷貝參考影片聲音。
- 聲音開關、音量控制：手機瀏覽器須經「開始對戰」或音效按鈕等使用者操作，才能啟用音訊；瀏覽器不支援 Web Audio 時可靜音執行模擬。
- 影音與物理：即時模式以相同事件 ID／時間觸發畫面與聲音。批次 25～1,000 場模式不播放聲音或動畫。
- 音效與特效的強弱使用**模型內部單位**；仍不表示真實的噪音分貝、撞擊能量、速度或 3D 接觸幾何。

**限制：** 現階段是受實際能力指標驅動的非寫實模型，不是官方遊戲客戶端，也不是該影片的逐格重製。戰鬥盤、零件外觀及碰撞物理尚未完成 CAD / 實測校正。

新增回歸測試：tests/sim-audio-smoke.cjs。

## V1.3 左右落點區、落地彈跳與 SP 操作（2026-11-16）

- 程式內部以場地中心作為初始落點分界。我方落在左半場，對手落在右半場。**畫面不繪製半場色塊、標籤或中心分界線**。競技盤保持完整連續。落地後雙方可任意跨越中線碰撞。
- 每回合依亂數種子產生兩個各自半場的落點、初始高度及微小落地速度差。即時畫面展示從盤面上方下降，首次著地小幅回彈，再落下穩定。尚未雙方著地時不觸發雙方碰撞。引擎提供 `height`、`verticalVelocity`、`landed` 與 `bounces`，3D／2D 共用同一份狀態。
- 2D 備援畫面以高度偏移及地面陰影呈現下落。Three.js 以真實的場景垂直座標呈現。首次落地的 `land` 事件帶有輕量原創提示音與視覺波紋。
- 發射力道介面改為 0～14000 SP。滑桿可快速調整（每格 100），數字輸入框可精確設定任意整數，並會自動限制到 0～14000。雙方各自獨立。重置設定恢復 10500 SP。
- 發射力道映射至引擎內部的無因次初始旋轉和移動速度。0 SP 表示不輸入初始旋轉動能。這是便於玩家設定的**自訂模型參數**；官方 BEYBATTLEPASS 所測 SP 數值可超過 14000，且本模型沒有官方 SP→RPM 換算表。勿將此模擬器上限解讀成官方硬體極限。
- 固定種子和相同設定能重現落點、落地動作、事件、回合結果。即時與批次模式沿用同一引擎。測試涵蓋半場落點、隨機種子重現、0 與 14000 SP 限制、落地事件及 UI 重置。
- 對照來源：[BEYBLADE X 官方 App](https://beyblade.takaratomy.co.jp/beyblade-x/app/) 的射擊資料功能與 [BX-09 BEYBATTLEPASS 官方手冊](https://beyblade.takaratomy.co.jp/beyblade-x/manual/BX-09_manual.pdf)。本網站未複製官方 App 的圖像、演算法或設備通訊。

## V1.4 發射傾斜、撞擊騰空、爆裂動態（2026-11-16）

- 原先角度滑桿只微調平面發射方向，且畫面沒有讀取 `tilt` 表示傾斜。V1.4 以角度同時控制初始平面速度方向、入場後短時間橫向偏移及 3D／2D 可見傾斜。滑桿調整會即時刷新靜態預覽，不重建整組 3D 模型；播放中更改仍會清除舊對戰。
- 初始落點仍限制在各自半場，半場限制**不會畫在競技盤上**，也不會成為任何碰撞障礙。
- 撞擊採用更強的法向反彈和少量切向擦撞擾動，並在模型內記錄 `impact`、`tilt`、`tiltVelocity`、`tiltDir`、`height` 及 `verticalVelocity`。較大的撞擊可把陀螺短暫彈離盤面，再受重力落回。盤邊反彈亦會造成輕微震盪。
- 增加有限的交會路徑修正，改善原本起始位置隨機造成大量零接觸回合的現象。這是視覺對戰近似，不代表陀螺具有真實吸引力。
- 爆裂門檻和撞擊負荷以已核對的能力向量作相對調整。攻擊強弱、軸心爆裂抗性與防禦能力均會影響結果。爆裂仍是可能事件而非保證事件，並保留爆裂、擊飛、極限、停轉的不同判定。
- 3D 顯示撞擊產生的實際高度、傾斜與分離部件動畫。2D 以縮扁透視、陰影、光效及拆散部件表現同一模型狀態。鏡頭震動、軌跡及撞擊音效會依事件同步加強。
- `tests/sim-smoke.cjs` 增加固定種子、角度正負方向與位移、撞擊騰空、強力碰撞樣本中能發生爆裂等回歸測試。`tests/sim-ui-smoke.cjs` 增加滑桿改變 3D 預覽傾斜且不重建幾何體的測試。
- **重要限制：** 本模型未使用實測質量、旋轉慣量、摩擦係數或零件扣合機構的校正資料。增加表現力不等於提高實物預測準確度。0～14000 SP 仍為網站自訂控制範圍，非官方 SP 量測校正。

### 這次修正

- 前一版依 240 場固定測試組合（兩方 10500 SP，角度 0°）測得平均接觸約 1.24 次，爆裂佔 145 場／240 場。此為前一版程式的計算輸出，並非上述影片實測。
- 擴大陀螺相對於盤面的碰撞佔位，並將 3D／2D 外形比例同步調整，避免視覺上接觸卻在模型中錯過。
- 發射初速依實際選用軸心的攻擊、平衡、防禦、持久類型設定不同活動程度；加入依種子決定的少量發射方向偏差，角度滑桿仍真正影響軌跡及傾斜。
- 攻擊傾向軸心加入小幅徑向花形路徑變化；持久軸心活動程度較低。這些都是未經實測校準的行為假設。
- Xtreme Line 觸發時不再僅沿盤邊切線加速，改為同時帶有盤內方向的短距離衝刺，並保留軸心衝刺能力差異。一般練習盤不會觸發衝刺。
- 重新平衡正常反彈與爆裂閾值，降低首次碰撞立即爆裂的情況，允許連續撞擊累積損傷；仍保留爆裂、擊飛、極限、停轉與平手等獨立終結。
- 3D 每次撞擊呈現多個火花粒子散射、短暫鏡頭震動及拉近；2D 同步呈現鏡頭震動與更明顯的放射火花。撞擊與衝刺音效全部使用原創 Web Audio 合成。
- 同種子＋同配置保留可重現性。左右半場只限制初始投放區，**不顯示分界線、色塊或隔板**。0～14000 SP 為使用者指定的自訂模擬輸入，不是官方 SP 量測公式。
- 新增回歸測試，檢查平均接觸次數、Xtreme Line 觸發、爆裂不會變成每場必然結果，以及一般練習盤不觸發導軌。**這些模型內統計不是實戰勝率預測。**
